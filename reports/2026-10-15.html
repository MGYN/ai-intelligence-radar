  1. AWS 开源补收：Strands Box（OS 隔离沙箱）+ Dogwood Local Engine（时序治理）+ TOLAP（工具返回对象级 ACL）

A−NEW（补收）国际C/F/GOSS blog 10-07 / 09-30 / 09-22注册表缺口后补

补收说明：三篇均在 AWS Open Source Blog；此前 Daily/快讯因注册表缺口漏扫（watchlist 51），本期合组。

发生了什么（事实）

  • Strands Box（Fernando Dingler，2026-10-07，developer preview，Apache 2.0）：OS 隔离（如 macOS Seatbelt）+ Dogwood 细粒度策略；嵌入 Dogwood Local Engine；强制点含 egress / Python(Monty) / Shell / MCP broker；事件统一如 fs:read、http:request；网关可代签凭证（agent 只见 placeholder）；box.toml + policy.dw；时序例：Slack 10 分钟内最多 3 帖。Repo：github.com/strands-agents/box；目前 macOS 优先，计划扩 OS / 部署到 AgentCore·ECS·K8s。
  • Dogwood Local Engine（Arora / Tassarotti / Tristan，2026-09-30，Apache 2.0）：嵌入式策略引擎，按历史时序 allow/deny；durable event log（redb）+ snapshot；动态策略更新；harness 负责 verdict 执行与事件完整性。
  • TOLAP（Phillip Spies，2026-09-22，Apache-2.0，github.com/awslabs/tolap）：工具返回数据的对象级 ACL（列/行/字段遮蔽等）；源点强制；.NET/Python/TS SDK + 14 框架集成；新增 purpose-binding、delegation chains、可选 LLM judge；非 MCP 协议本身。

我的判断

  • 这是目前公开材料里较完整的「沙箱 + 时序政策 + 工具回传脱敏」开源栈，可直接对标 Windows MXC、NVIDIA OpenShell、Workday C1 权限模型。
  • 价值在组合：隔离（Box）解决「能跑什么」，Dogwood 解决「按历史限频/限序」，TOLAP 解决「工具看见什么」——三者缺一，Agent 权限模型就不完整。
  • 保留：均为 preview / 博客级；macOS 优先；与 Bedrock AgentCore 产品化路径未在本稿写死。

往后看：是否进入 AgentCore 正式产品；跨 OS；与 MXC / OpenShell 互操作叙事；社区采用。

对智能体互联网：强相关。delegation chains + purpose-binding + 凭证 placeholder，是跨 Agent 委托时可抄的字段与执行点设计。

对 Work / Agent 引擎：强相关。Sandbox 强制点清单、时序政策引擎、工具回传 ACL，可映射到自家 Runtime / Harness / MCP broker。

建议动作：① 读三篇 + 对照 MXC 事件模型，列「强制点 × 时序 × 回传 ACL」缺口表；② PoC：工具回传字段遮蔽是否进 Context 管线。
