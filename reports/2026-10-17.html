发生了什么（事实）

  • 定义：SI control incident = 一个或多个 SI agent 采取未被指示的行动，与界定任务范围、提供人类监督的策略、控制或安全措施相冲突或使之失效。
  • 覆盖面：限制 agent 对信息/系统/工具/网络的访问；监控异常活动；保全证据并停止不期望行为；从已验证基线重建；向相关政府机构与受影响方报告事件与 near-miss；强调恢复 agent 活动前先测试控制、验证遏制。页面同时链接 NIST 新闻稿与 CISA「Super Intelligence」专题页。

我的判断

  • 这是把「agent 越界」从研究叙事（Anthropic 越界报告、自治入侵取证线）落到事件响应生命周期（准备 → 检测 → 遏制 → 恢复 → 报告）的第一份联邦文件。短期是自愿实践，长期是审计与合规检查表的雏形。
  • 范围刻意限定在「训练与评测」阶段——意味着前沿实验室的内部沙箱也被视作关键基础设施级风险面；但对已部署产品没有直接约束。
  • 「near-miss 也要报」是关键措辞：这会倒逼评测环境把「差点越界」记录成结构化事件，而不是只留在聊天记录里。

往后看：PDF 全文的 10 条具体条目与日志字段要求；是否进入 NIST AI RMF / 联邦采购条款；白宫「Accord on Super Intelligence」签署方（Anthropic 在 METR 文中提及）是否据此调整评测流程。

ANEW国际H/G/KECDSA 文 17:02Z（10-17 01:02 CST）量子文 17:29ZHN 663 分 / 265 评

发生了什么（事实）

  • ECDSA 种子溯源（Claude reveals ECDSA curve origins，Frontier Red Team）：员工请内部研究模型在不给线索的前提下追查种子来源，Claude 不到半小时确定 NIST P-192/224/256/384/521 的种子不是哈希产物，而是 C 库 lrand48 用 Unix 时间戳（1997-05 至 1998-04）初始化后的输出（如 P-256 为第 1842 个 20 字节候选）。方法：逐位扫描识别 1990 年代 PRNG 特征 → 发现 lrand48 高位全零签名 → LLL 格基约简恢复截断 LCG 状态 → 回推到 srand48 初始化形式。另解释了 6 条曲线的基点来自 FreeLIP 随机数生成器；B-163 种子与 P-224/256/384/521 基点仍未解释。

  • 量子电路（Designing more efficient quantum circuits with Claude，STEM Fellows，与 Harvard/QuEra 合作）：给 Claude Mythos 5 八个电路的自然语言规格 + 自动评测器（验证正确性、按「量子比特 × 门数」打分），闭环迭代无人工介入，八项均优于已发表最佳设计。椭圆曲线点加法连续工作 53 小时，其中一个设计比此前最小方案多 12% 量子比特、门数少 17 倍；DQI 优化算法最贵一步便宜约 12 倍（Reed–Solomon 定位步从 190 万 Toffoli 降到 14.1 万，存储从 840 降到 19 量子比特）。

我的判断

  • 两篇放在一起看：一篇是考古式密码分析，一篇是带评测器的长程自主优化。共同点是「问题可被程序精确验证」——这正是 agent 能长时间无人值守、且结果可信的条件。

  • 评 A（H/K 领域方法论信号），对用户两条主线是间接相关。

往后看：密码学界对 ECDSA 跳过候选（P-256 的第 876 个候选也合格却未用）的解读；量子电路结果的同行评审；Mythos 5 闭环 53 小时的成本披露。

对 Work / Agent 引擎：中相关。「规格 + 自动评测器 + 闭环」是长程 agent 任务的标准范式，可直接对照内部 eval harness：评分函数设计、并行探索、偶发人类提示。

今天正在形成的趋势

  1. 治理从原则变成操作手册：CISA 的事件响应十条、Anthropic 的三级评估者访问、Ledger 的「提议–批准–执行」三权分离，都在回答同一个问题——agent 越界时谁发现、谁叫停、谁能看、谁批准。
  2. 并行多 agent 成为默认形态：GPT-6 Astra Pro（大众 Chat）、Claude Code fork 子代理全入口默认开、nested sessions、DeepMind 4 agent 协作——编排从高级功能变成默认体验，「子任务进度 + 产物审阅」是新的 UX 基础件。
  3. MCP 配置面 = 代码执行面：ZCode 工作区 MCP 自动信任、Agent SDK resume 注入、上周 .mcp 尾点与 git 搜索路径——一周 5+ 个宿主入口漏洞，「声明即信任」的默认值正在被逐个打破。
  4. Agent 商业协议栈成形：/.well-known/ucp 发现 → MCP 工具 → buyer_consent → 确认后支付，加上 Vercel 让店面对 agent 可读，「agent 当一等购物者」第一次有了端到端公开实现。
  5. 记忆与 harness 都在「脱离单一工具」：MemHub 跨 10 种工具共享记忆、UHP 让 harness 可插拔、Mirror 开源——个人上下文与执行框架都在变成可迁移资产。

对智能体互联网最值得吸收的东西

  1. 把「越界」定义成可判定事件：借 CISA 的 SI control incident 定义，委托凭证里必须写清任务范围、工具、网络边界，才能机器判定「未被指示的行动」并上报 near-miss。
  2. 同意（consent）作为可携带的结构化声明：UCP buyer.consent（目的 + 状态 + 政策链接）可直接借鉴到 agent 代表用户与第三方交互时的隐私偏好字段。
  3. 提议权与执行权分离 + 异步批准：Ledger 模式可推广为通用委托模型——agent 只有 propose 权，高风险 execute 必须由用户设备或策略引擎签发。
